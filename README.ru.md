# dsh-opencode-routing

[English](README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · **Русский**

Плагин для [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) (`dsh`), который объединяет два
прежних плагина в один пакет: **пул аккаунтов OpenCode с автоматическим переключением A→B и маршрутизацией по
квоте**, а также **панель использования по аккаунтам и моделям**. И то и другое живёт на одной странице Settings —
«Аккаунты и использование OpenCode».

- **Клиент**: одна `settings.section`, обновляемая каждые 60 с; аккаунты можно добавлять, редактировать,
  переставлять и проверять; карточки моделей несут теги возможностей; обе таблицы прокручиваются перетаскиванием;
  интерфейс говорит на 10 языках (язык браузера имеет приоритет).
- **Хост**: два эндпоинта — `GET /opencode-usage.json` (использование, `?refresh=1` принудительно обновляет) и
  `GET|POST /opencode-quota-router.json` (пул и маршрутизация; действия ниже).

## Установка

```bash
npm i dsh-opencode-routing
```

Пакет поставляется со своим `cordis.patch.yml`: он объявляет провайдеров `opencode-go` / `opencode-free` и
**единственную** вставку (`id: opencode-router`). Подобъекты `usage:` и `router:` хранят настройки каждой половины
(у обеих есть `path`, поэтому они не могут делить одно плоское пространство имён).

```yaml
- insert:
    - id: opencode-router
      name: 'dsh-opencode-routing'
      config:
        usageUrl: https://opencode.ai/inference/go/v1/usage
        apiKeyRef: OPENCODE_API_KEY
        usage:
          path: /opencode-usage
          plan: go
        router:
          path: /opencode-quota-router
          routes:
            - primary: { provider: opencode-go, model: deepseek-v4.1-flash }
              fallback: { provider: deepseek-account, model: deepseek-flash }
```

Ключи верхнего уровня применяются к обеим половинам (`usageUrl`, `apiKeyRef`, `probeIntervalMs`, …); ключи внутри
подобъекта переопределяют только свою половину.

## Пул аккаунтов и переключение при отказе

Порядок пула — это порядок использования. В любой момент «текущим» является ровно один аккаунт, и его ключ
зеркалируется в ссылку на учётные данные, которую читает провайдер (по умолчанию `OPENCODE_API_KEY`). Поэтому
переключение аккаунтов не требует изменения конфигурации провайдера: `resolveApiKey` выполняется после того, как
маршрутизатор `llm/stream` выберет аккаунт, при каждом потоковом вызове.

- **A исчерпан — B подхватывает**: при `QUOTA` / `ACCOUNT_QUOTA` / 429, когда официальный лимит подтверждённо
  израсходован, или при ошибке класса аутентификации (`AUTH`, `INVALID_CREDENTIAL`, `MISSING_CREDENTIAL`,
  `ACCOUNT_SIGN_IN_REQUIRED`, `CLIENT_UPGRADE_REQUIRED`) текущий аккаунт помечается непригодным (до сброса окна, а
  при сбое аутентификации — на 30 минут), маршрутизация переходит к следующему включённому аккаунту и **повторяет
  тот же шаг** — ход никогда не деградирует.
- **Карантин одной модели**: когда лимит исчерпан только у одной модели, а в пуле ещё есть бюджет, карантин
  применяется только к этой модели (по умолчанию 30 минут); все остальные модели продолжают работать по плану.
- **Пул исчерпан целиком**: только тогда маршрут откатывается на свой `fallback` (по умолчанию — аккаунт
  DeepSeek), а каждые 30 минут (или при сбросе скользящего окна) выполняется проба `GET /inference/go/v1/usage`,
  не тратящая токены, которая автоматически возвращает на план.
- **Сброс**: «Сбросить метки блокировки» в Settings очищает все метки исчерпания и аутентификации и немедленно
  возвращает в пул. Аккаунты и ключи не затрагиваются.

## Панель использования

Официальный эндпоинт `/inference/go/v1/usage` возвращает только округлённые проценты по скользящему / недельному /
месячному окну и **без разбивки по моделям**, тогда как план тарифицирует каждую модель отдельно (5 ч = 20 %
месячного лимита, неделя = 50 %, месяц = 100 %). Поэтому страница показывает два набора чисел:

- **Официальные проценты** (одна строка на аккаунт): прямо из API — реальное использование аккаунта, включая другие
  клиенты и другие машины.
- **Деньги по моделям** (таблица моделей): локальная оценка. Она пересканирует `$DSH_HOME/sessions` за последние
  40 дней и учитывает только события `assistant/message`, у которых поле provider начинается с `opencode`, по
  публичным тарифам (включая 2× пиковое окно DeepSeek). У использования из других инструментов нет локальной записи.

«Посмотреть использование» открывает диалог по аккаунту с тремя окнами, их временами сброса и результатом пробы
(проверяется только этот аккаунт, модели при этом не переключаются).

«Изменить ключ» получает текущий ключ аккаунта из `GET /opencode-quota-router.json?key=<account id>` и заполняет
поле ввода (эндпоинт только локальный; снимок списка всегда несёт лишь маску). Названия моделей следуют регистру
вендора (`deepseek-v4.1-flash` → `DeepSeek V4.1 Flash`); вендоры с опубликованным фирменным знаком отображаются
встроенным SVG, остальные — буквенным бейджем. «Следующая проба» — настоящий таймер (по умолчанию 30 минут), и
страница перерисовывается каждую секунду, поэтому он идёт обратным отсчётом; открытие страницы только читает
снимок и никогда не запускает пробу.

«Что сейчас выгоднее» выводится из выгоды подписки: Go берёт $10 за $100 лимита по прайс-листу (≈ ¥710), поэтому
OpenCode всегда стоит 10 % официальной цены — на 90 % дешевле. Реальные данные никогда не в пользу официального
API.

Столбец возможностей берётся из того же каталожного эндпоинта (`/inference/go/v1/models`): `modalities.input` и
`capabilities` отображаются как текст / изображение / видео / аудио / PDF, вызовы инструментов, рассуждения, плюс
длина контекста. Модели с нулевой ценой показывают «безлимит».

### Пиковые / непиковые часы и праздники

Непиковое окно DeepSeek — всё время вне пекинских понедельника–пятницы 09:00–12:00 и 14:00–18:00 (включая
обеденный перерыв, ночи, выходные и **официальные государственные праздники**) ровно по половине пиковой цены.
OpenCode считает пиковыми только UTC понедельник–пятницу 01–04 и 06–10 и **игнорирует китайские государственные
праздники** (anomalyco/opencode#53071, мейнтейнер: *"Go pricing follows our own schedule, not DeepSeek's holiday
calendar."*).

Плагин поставляет таблицу китайских государственных праздников на 2026–2031 годы. Она применяется к официальной
стороне только при `holidayAware: true` (`usage.holidayAware`); по умолчанию выключено, поскольку OpenCode в эти дни
продолжает брать пиковую цену. Таблица живёт в `usage.js` как `HOLIDAYS`, а `isChinaHoliday()` можно вызывать
отдельно.

Цену подписки и её лимит можно переопределить через `usage.planPriceUsd` / `usage.planAllowanceUsd`; скидка на
странице выводится из этих двух чисел, поэтому изменение плана со стороны OpenCode — это правка конфигурации, а не
патч.

## API настроек

`GET /opencode-quota-router.json` возвращает `{mode, reason, active, accounts[], quarantine[], routes[],
lastFailure}`; ключи аккаунтов всегда маскируются (`hint`). `POST` на тот же путь с `{action, ...}`:

| action | аргументы | эффект |
| --- | --- | --- |
| `add` | `label?`, `key` | создать аккаунт (ключ ≥ 8 символов), сохранить и проверить |
| `update` | `id`, `label?` / `enabled?` / `key?` | переименовать, отключить/включить, сменить ключ |
| `remove` | `id` | удалить аккаунт и его ключ (один всегда остаётся) |
| `activate` | `id` | переключиться на него сейчас |
| `move` | `id`, `direction: up\|down` | изменить порядок |
| `probe` | `id?` | проверить все аккаунты или только один |
| `reset` | — | очистить метки исчерпания/аутентификации и вернуться в пул |

`GET /opencode-usage.json` возвращает `{plan, configuredPlan, detectedPlan, holidayAware, peak, usage,
accounts[], activeAccount, models[], totals}`; `?refresh=1` сначала принудительно запрашивает свежий официальный
снимок.

## Языки

Строки интерфейса лежат в `DICT` в `client.js`: `zh` (исходный), `zh-tw`, `en`, а также `es` / `fr` / `de` / `pt` /
`ja` / `ko` / `ru` (встраиваются из файлов переводов скриптом `scripts/merge-i18n.mjs`; отсутствующий ключ
откатывается к `en`, затем к самому ключу). `localeOf()` сопоставляет префикс языка браузера и различает
упрощённый и традиционный китайский.

## Тесты

```bash
node test.mjs
```

Квота модели не требуется: поддельный контекст, поддельное хранилище учётных данных, поддельный webServer и
локальный эндпоинт использования, отвечающий по каждому API-ключу. Покрытие: составное монтирование, принятие
аккаунта, карантин одной модели, переключение A→B с зеркалированием ключей, проба по аккаунту, откат на весь пул,
сброс, валидация действий настроек, представление использования (теги возможностей, безлимитные модели, расчёт
пик/непик, строки биллинга) и деградация до одного аккаунта.

## Связь со старыми пакетами

`dsh-opencode-quota-router` и `dsh-opencode-usage-settings` — его предшественники; всё, что они умели, объединено
здесь. Оба помечены на npm как deprecated и указывают на этот пакет. Прежние репозитории удалены, этот — единственный источник.
